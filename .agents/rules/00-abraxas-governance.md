# ABRAXAS Workspace Governance

Read `AGENTS.md` before consequential work.

Sequence:
BASELINE -> OWNERSHIP -> AUDIT -> CLASSIFY -> PLAN -> IMPLEMENT ->
VERIFY -> DIFF -> REPORT.

Do not infer implementation from reference folders, backups, continuity
packages, historical GREEN evidence or design documents.

Prefer modular changes with explicit contracts and narrow ownership.
Do not commit or push unless explicitly authorized.
