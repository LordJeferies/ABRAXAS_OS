# Desktop Layout Rules

Target inicial:
~1440 × 900.

Mínimo:
~1100 × 720.

Wide:
rail + center + inspector.

Medium:
rail icon-only y inspector algo más compacto.

Narrow desktop:
hacer inspector toggleable/drawer antes de aplastar el preview.

Scroll:
body/window no es página vertical.
Inspector/transcript tienen scroll propio.
Timeline usa scroll/zoom horizontal.

Sidebar:
colapsable/ocultable.

Keyboard:
diseñar desde el inicio para focus y shortcuts.

## Caption document responsiveness
En desktop amplio:
- timeline + caption document en modo split por defecto.

En tamaño medio:
- workbench puede alternar `Split / Timeline / Document`, pero debe existir una
  forma de volver al caption document en un clic.

Regla:
siempre debe existir una vista clara para leer captions completos sin depender
solo del timeline.

## Docking rules
Desktop wide:
- layout modular completo.
- bottom workbench puede reacomodarse.

Desktop medium:
- permitir colapsar/stackear paneles.

Floating windows:
- preview detached;
- inspector detached;
- caption document detached;
- future secondary monitor workflows.
