# ABRAXAS v4.3.4 Adaptation

El workflow ABRAXAS entregado se usa como disciplina de arquitectura/QA,
no como estilo visual obligatorio.

Adoptar:
- VAV = Dashboard / Operational Workspace;
- no vertical dump;
- information architecture antes de CSS;
- una top-level view activa;
- contextual scroll;
- art direction brief;
- glass funcional;
- visual QA obligatorio;
- preservation of real contracts;
- progressive disclosure;
- critic/convergence pass.

No adoptar:
Three.js obligatorio.
VAV captions no necesita 3D decorativo.

Regla:
workflow clarity > spectacle.
