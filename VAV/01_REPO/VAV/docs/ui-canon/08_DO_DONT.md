# Do / Don't

DO
- preview first;
- un solo acento fuerte;
- profundidad por materiales;
- selección inequívoca;
- inspector contextual;
- timeline semántico;
- progressive disclosure;
- keyboard workflows;
- motion spring moderado.

DON'T
- fake browser chrome;
- fake macOS traffic lights;
- glass everywhere;
- mobile bottom tab bar on desktop;
- convertir VAV en full NLE;
- random gradients;
- tiny icon hitboxes;
- over-round everything;
- dashboard analytics por encima del editor;
- body scroll kilométrico.
