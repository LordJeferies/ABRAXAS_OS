de Apple y el workflow ABRAXAS entregado por el usuario en un sistema
reproducible de UI/UX para VAV.

No obliga a clonar una referencia. Define qué tomar, qué descartar, cómo
adaptarlo a desktop Mac/Windows, tokens, componentes, motion y QA.
