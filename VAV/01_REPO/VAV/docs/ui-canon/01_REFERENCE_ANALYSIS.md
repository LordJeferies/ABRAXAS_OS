# Análisis de las referencias visuales

## Referencia 01 — Editor desktop profesional y denso
Tomar:
- preview dominante;
- rail vertical compacto;
- inspector separado del canvas;
- timeline inferior como plano propio;
- estados de herramienta claros;
- relación directa entre selección y panel de propiedades.

Evitar:
- chrome de navegador falso;
- demasiados bordes anidados;
- herramientas de NLE irrelevantes para captions.

Traducción VAV:
rail caption-centric + inspector contextual + preview Remotion dominante +
timeline de escenas/captions/motion.

## Referencias 02–03 — Editor móvil
Tomar:
- selección de alto contraste;
- targets táctiles claros;
- lanes de timeline con color funcional;
- agrupación simple de controles;
- relación obvia entre objeto seleccionado y sus propiedades.

No copiar a desktop:
- tab bar inferior;
- geometría de iPhone;
- safe areas de Dynamic Island/Home Indicator.

## Referencia 04 — Editor desktop premium oscuro
Es la referencia principal de art direction:
- near-black;
- paneles charcoal;
- profundidad por luminancia;
- acentos fríos muy controlados;
- preview como foco;
- inspector por bloques;
- timeline respirable.

## Referencia 05 — Consola premium
Tomar:
- jerarquía espacial fuerte;
- superficies oscuras con profundidad sin sombras pesadas;
- controles circulares/squircle;
- estados primario/secundario/inactivo muy claros;
- agrupación visual precisa.

## Referencia 06 — Editor simplificado claro
Tomar:
- legibilidad extrema de timeline;
- pocas acciones primarias;
- selección evidente;
- canvas despejado;
- relación media/timeline intuitiva.

No tomar:
- tema claro por defecto;
- sensación de editor web genérico.

Síntesis:
claridad de la ref. 06 + profesionalismo de 01 + art direction de 04 +
disciplina de controles de 05 + feedback de selección de 02/03.

## Referencia 07 — Riverside-style subtitle reading/workbench view
Tomar:
- un espacio persistente donde el usuario pueda leer los subtítulos completos;
- sincronía clara entre reproducción, texto y selección;
- lectura por bloques/utterances completos, no solo chips pequeños en timeline;
- combinación de preview + texto + waveform/timeline en la misma sesión de trabajo;
- resaltado de la línea activa y navegación inmediata desde el texto.

No copiar literalmente:
- layout exacto;
- branding;
- paneles que no sirvan al flujo de VAV.

Traducción VAV:
VAV debe tener un `Caption Document View` o `Subtitle Reading Panel`
siempre accesible, con el texto completo de captions visible y sincronizado,
además del timeline.

## Referencias 08 y 09 — Docking / splitting / detachable windows
Tomar:
- capacidad de ensamblar paneles en distintas zonas;
- divisores para redimensionar paneles;
- sacar una superficie a ventana independiente sin dejar de pertenecer al mismo programa;
- continuidad de estado: sigue siendo el mismo proyecto, no otra app;
- sensación de workstation profesional.

No copiar literalmente:
- branding de CapCut;
- iconografía específica;
- distribución exacta.

Traducción VAV:
VAV debe tener un `Workspace Layout Manager` con docking, resizing, panel split,
y detach-to-window para paneles seleccionados.
