# Editor Interaction Foundation

## Command Registry
Central shortcuts, not handlers scattered through components.

Initial commands:
Space play/pause
Cmd/Ctrl+Z undo
Cmd/Ctrl+Shift+Z redo
Cmd/Ctrl+F find
Cmd/Ctrl+S save
M marker
Cmd/Ctrl+E export
