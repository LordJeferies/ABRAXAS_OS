# VAV Captions — Pro Editor Foundation V1

Este paquete formaliza los fundamentos profesionales que Vav-captions necesita
además del caption engine visual.

Objetivo:
evitar construir primero una interfaz espectacular y descubrir tarde que faltan
los fundamentos de una herramienta de edición profesional.

Este documento no añade scope de edición general de video.
Todo sigue centrado en captions.
