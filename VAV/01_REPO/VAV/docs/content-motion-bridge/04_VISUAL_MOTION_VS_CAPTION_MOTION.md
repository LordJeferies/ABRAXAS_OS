# Visual Motion vs Caption Motion

Never call both simply "motion" internally.

## Visual Motion
Narrative visual treatment occupying/altering the picture:
Motion 00–07, B-roll, infographic, visual replacement, foreground object, etc.

Example ID:
VMOT-0032

## Caption Motion
Animation behavior applied to subtitle typography:
Slide Blur Lite, Pop, Fade, Shake, Scale Punch, etc.

Example ID:
CMOT-0017

A Visual Motion can request a Caption Motion or restrict it, but it does not
become the caption animation itself.

Example:
Visual Motion 03 = typographic full-frame statement.
Caption standard layer may be suppressed.
The visual motion typography owns the phrase.

Example:
Visual Motion B-roll = standard captions stay visible.
Scene Smart places captions in a functional region.
