# Scope Boundaries

VAV-Captions owns:
- transcript/caption semantics;
- caption visual composition;
- caption response to motion context;
- importing content/motion/edit manifests;
- preview/render of caption layer.

Future Vav-motions may own:
- creation/generation/authoring of visual Motion 00–07 assets;
- visual motion timeline authoring;
- exporting Motion Manifest.

Future Vav-cuts owns:
- clip selection/cutting;
- source→timeline edit mapping;
- exporting Edit Manifest.

Future Production OS / orchestrator may coordinate all manifests.

This prevents VAV-Captions from becoming a general NLE.
