# Pro Editor Foundation Decision

VAV-Captions must include professional editor fundamentals from the architecture
stage, not bolt them on after the caption intelligence is mature.

Systems:
history, commands, selection, snapping, project session, autosave/recovery,
migrations, relink, fonts, review, navigator, property resolution/locks,
caption tracks, speakers, QC, export queue, brand kits, versioned presets.

General media/NLE/AI generation tools remain outside Vav-captions.
