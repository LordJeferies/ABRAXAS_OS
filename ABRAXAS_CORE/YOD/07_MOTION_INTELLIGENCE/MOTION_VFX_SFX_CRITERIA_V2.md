# Motion / VFX / SFX Criteria V2

## Motion

Debe responder:
- función narrativa;
- por qué aquí;
- por qué esta familia;
- duración;
- relación con source/captions;
- qué preservar;
- alternativa si debilita el gesto humano.

Tratamientos:
KEEP_SOURCE
PLATES_CLOSEUPS
TYPOGRAPHIC
INFOGRAPHIC
DIAGRAM
MICROSEQUENCE
SYMBOLIC_OBJECT
PIP
TRACKED_SURFACE
BEHIND_SUBJECT
PARALLAX
PERSPECTIVE_3D
OTHER_REGISTERED_FAMILY

## Si solo hay fotos

Arquitecto puede recomendar:
- slow push;
- pan;
- crop/reveal;
- foreground/background separation;
- 2.5D parallax;
- light/shadow drift;
- depth camera;
- masks;
- subtle perspective;
- text layer motion.

## Frame sequence

START / MIDDLE / END
con continuidad estricta.

## Full animation

Motion generado o compuesto.

## Source + Motion

Mantener persona/source y añadir capas detrás/lateral cuando sea mejor.

## VFX

No demuestra destreza técnica.
Sirve para:
aclarar
visualizar
enfatizar
conectar
cambiar estado

Cada VFX declara:
WHAT CHANGES
WHEN
TRIGGER
WHY
DURATION
PLACEMENT
PRESERVE
NEGATIVES

## SFX

Cada sonido declara:
SOUND
WHEN
TRIGGER
LEVEL
FUNCTION

Si no hay evento justificable:
`no_sfx_needed`.

No llenar todo de whooshes.

## Captions

No recrear captions dentro de imágenes.
Mantener safe areas y capa separada.
