# Copy Intelligence Canon V2

## Tesis

El copy no es una sinopsis automática.

Funciones:
CONTEXTUALIZE
EXTEND
TRANSFER
CONVERT
DISCUSS
SOURCE
FRAME

## Nace temprano

YOD puede crear:
- master copy draft;
- variantes de plataforma;
- CTA options;
- headlines/captions.

Shim puede:
- verificar contra source real;
- marcar OUT_OF_SYNC;
- actualizar desde resolved content;
- señalar claims no sustentados.

Arquitecto puede:
- revisar;
- sugerir;
- crear alternativas;
- explicar;
- guiar edición.

El usuario puede editar en cualquier etapa.

## Modelo

copy.master
copy.platforms.instagram
copy.platforms.linkedin
copy.platforms.tiktok
copy.platforms.youtube
copy.platforms.other[]

Cada uno:
version
source
based_on_lienzo_version
status
created_by
updated_by
change_reason

## Perfil de plataforma

Instagram:
contexto + conversación + acompañamiento.

LinkedIn:
tesis + aprendizaje + implicación; puede funcionar autónomamente.

TikTok:
directo y corto sin perder voz.

YouTube:
título + framing + descripción + CTA/discovery cuando corresponda.

## Consistency

Si el contenido final cambia:
- verificar copy;
- no sobrescribir silenciosamente;
- marcar OUT_OF_SYNC;
- mostrar impacto;
- crear nueva versión.
