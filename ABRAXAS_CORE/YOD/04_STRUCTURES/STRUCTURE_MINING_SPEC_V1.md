# Structure Mining

Objetivo: descubrir estructuras replicables más allá del nicho.

Pipeline:
1. indexar corpus;
2. extraer piezas;
3. identificar hook/thesis/functions/progression/reengagement/payoff/CTA/format/length/speaker/visual/evidence;
4. convertir nombres locales a funciones semánticas;
5. clusterizar;
6. detectar equivalencias;
7. separar Universal / Industry / Client;
8. conservar provenance y ejemplos;
9. actualizar Structure Registry;
10. validar con lotes reales.

## Structure Genome

Cada Lienzo puede guardar:
hook
progression[]
reengagement
payoff
cta
speaker_mode
visual_mode
evidence_mode

Esto permite analizar repetición y performance.
