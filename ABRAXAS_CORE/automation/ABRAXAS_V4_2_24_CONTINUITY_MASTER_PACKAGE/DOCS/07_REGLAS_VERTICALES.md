# Reglas verticales

- IDs exactos: V01–V18, JV01–JV11 y MV01–MV08; total 37.
- Contrato editorial de duración: 45–80 s.
- El vertical se conserva como video completo; no se crean partes físicas periódicas.
- Exactamente seis ventanas Motion cronológicas: HOOK, TENSION, CORE, SHIFT, MEMORABLE y CLOSE.
- Cada ventana dura 4–9 s y no se superpone con otra ventana seleccionada.
- Una ventana seleccionada no obliga a sustituir al speaker: placement y alternativa mandan.
- Los diez excesos de duración heredados son warnings visibles, no correcciones falsas.

El renderer aislado V4.2.24 elimina la antigua creación de `FRAGMENTS` verticales. Los únicos clips cortos permitidos son `SOURCE_REFERENCE.mp4` dentro de una carpeta Motion seleccionada.
