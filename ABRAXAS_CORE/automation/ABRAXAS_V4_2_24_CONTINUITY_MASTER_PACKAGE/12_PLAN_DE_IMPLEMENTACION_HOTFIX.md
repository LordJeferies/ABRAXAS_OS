# Plan de implementación

1. Detectar masters y output en la ruta del proyecto.
2. Leer HTML base, SRT y resoluciones aprobadas.
3. Construir candidatos 4–9 s sin partición fija.
4. Seleccionar seis roles para cada vertical y ~2/min para cada horizontal.
5. Asignar M1–M6 con contrato V7, razón y alternativa.
6. Escribir mapa, cola, prompts, TXT, carpetas y Content Engine.
7. Crear Intro Lab aditivo y verificar hash del núcleo.
8. Crear referencia completa de transcripción <=9 s y probar que no pierde palabras.
9. Opcionalmente renderizar clips de referencia seleccionados.
10. En producción completa, instalar runtime aislado, compilar, fingerprint, assets, plan y render workers A/B.
11. Validar counts, duraciones, densidad, orden, hashes y shell syntax.
