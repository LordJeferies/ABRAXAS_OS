ARCHIVOS CLAVE
- SISTEMA_MAESTRO_MOTIONS_ABRAXAS_V4.html : manual navegable completo.
- PROMPT_INICIO_NUEVO_CHAT_V4.txt : úsalo al iniciar otro chat.
- PROMPT_MAESTRO_APLICAR_MOTIONS_V4.txt : compilador de Motions para una serie.
- CONTEXTO_MAESTRO_PARA_NUEVO_CHAT_V4.md : decisiones ya fijadas.
- REGLAS_MOTION2_TEXTO_EXACTO_V4.md : regla exacta de 3 segmentos.
- ANALISIS_REFERENCIAS_VISUALES_V4.md : ADN de REF A–E.
- OUTPUT_SCHEMA_MOTIONS_V4.json : estructura de salida.
- SOURCE_CRITERIOS_CLIENTES_ABRAXAS.txt : criterios fuente JOC/Moka/INENERGY.
- refs_visuales/ : referencias originales para que otra IA pueda inspeccionarlas.

USO RECOMENDADO
1. En un nuevo chat, sube este ZIP.
2. Sube además el ZIP del cliente o proyecto que quieres procesar.
3. Sube/pega las transcripciones o la serie de contenidos ya definida.
4. Pega PROMPT_INICIO_NUEVO_CHAT_V4.txt.
5. Luego usa PROMPT_MAESTRO_APLICAR_MOTIONS_V4.txt para procesar la serie completa.

El contenido fuente manda. El sistema agrega dirección visual y Motion; no inventa ni reescribe claims/citas/diálogo.
