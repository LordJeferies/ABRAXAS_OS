# CONTEXTO MAESTRO — CONTINUAR EL SISTEMA DE MOTIONS EN CUALQUIER CHAT

## Objetivo
Este paquete define un sistema de 6 Motions para aplicar dirección visual, imágenes generadas, infografías, tipografía e interfaces a contenidos audiovisuales ya determinados.

## Flujo de uso en un nuevo chat
1. Subir este ZIP.
2. Subir el ZIP del cliente/proyecto nuevo.
3. Subir o pegar la serie de contenidos/transcripciones/guiones.
4. Usar `PROMPT_MAESTRO_APLICAR_MOTIONS_V4.txt`.
5. Pedir que NO reescriba contenido aprobado y que añada Motion beat por beat.

## Principios fijados
- Imagen primero, animación después. Una imagen debe funcionar como still.
- Cada frame tiene resumen visual rápido + descripción cinematográfica completa. El resumen nunca sustituye la descripción larga.
- La descripción larga debe ser espacial y sensorial: foreground, midground, background, materiales, texturas, luz, cámara, lente, profundidad, perspectiva, posiciones, acción, significado y restricciones.
- Las referencias A–E son gramáticas visuales. Extraer jerarquía, densidad, profundidad, textura, tipografía y metáfora; no copiar contenido original.
- Las metáforas pueden ser creativas y alegóricas, pero deben conservar expresión profesional/corporativa y explicar el mecanismo real.
- Motion 1: si hay footage, generar solo background plate flexible; nunca generar al speaker. Si hay voice over, usar 3 close-ups coherentes.
- Motion 2: 4 clean plates; texto exacto de la transcripción dividido en 3 segmentos acumulativos; timing proporcional al audio; texto integrado físicamente en la escena.
- Motion 3: tipografía pura.
- Motion 4: una infografía master recorrida en Z.
- Motion 5: microsecuencia wide→detail→result, sin texto editorial, no intro principal.
- Motion 6: input→process→output con UI limpia, no HUD.
- Los 6 Motions pueden aplicarse a horizontal, vertical, podcast intro y voice over, adaptando composición y densidad.
- Aplicar Client Quality Pack real: JOC, Moka e INENERGY tienen lógicas distintas. Un nuevo cliente debe aportar su propio pack.
- No inventar citas, claims, evidencia, proyectos, códigos o datos.

## Entrega esperada por beat
Motion sugerido + alternativo; por qué; resumen visual; relación con frase; capa simbólica; reference DNA; speaker behavior; frames; imagen exacta; texto exacto; prompt de imagen; prompt de animación; continuidad; QA.
