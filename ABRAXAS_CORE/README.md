# ABRAXAS Core

ABRAXAS Core stores the functional local ABRAXAS systems selected from the
Phase 3 / Phase 3B forensic audits.

## Structure

- `content_engine/` — Content Lab and Content Operations
- `automation/` — orchestration / continuity automation
- `motion_intelligence/` — motion automation/intelligence systems
- `workers/` — production/resume worker systems
- `manifests/` — reserved for canonical portable manifests
- `legacy_functional/` — runnable previous generations and hotfixes

See `CANONICAL_SYSTEMS.md`.

ABRAXAS_CORE is part of the local ABRAXAS OS workspace. It is NOT automatically
inside the VAV Git repository.
