# Calendar + Backlog

Debe existir:
UNSCHEDULED / NO PROGRAMADO.

Drag/drop:
backlog → fecha
fecha → fecha
fecha → backlog

Un Content puede tener varias `publication_targets`.

Ejemplo:
Instagram lunes 10:00
TikTok lunes 18:00
LinkedIn martes 09:30

Una target ya programada puede quedar bloqueada sin congelar las demás.
