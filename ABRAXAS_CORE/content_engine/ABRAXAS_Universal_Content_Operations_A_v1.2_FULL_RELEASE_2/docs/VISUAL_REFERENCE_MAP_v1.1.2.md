# ABRAXAS v1.1.2 · Visual Reference Map

This document records which visual references and ABRAXAS technique IDs are used by each module. The 9 uploaded videos are quality references, not assets copied into the product. Contact sheets are packaged under `references/visual_research_v112/`.

## Global rule

- Dashboard / Workspace is the operating surface.
- Product Story is a second representation of the same state for Home, Clients, Brand Intelligence and Roadmap.
- Liquid Glass belongs to controls/navigation/utility windows, not the content layer.
- Story references: videos 1, 4, 6, 7. Workspace reference: video 9. Explorer reference: video 5.
- A technique is implemented only when it improves a task; decorative use is rejected.

## Apple current-design interpretation

Apple HIG/WWDC25 is the UI authority: hierarchy first, functional material above content, concentric geometry, familiar sidebar/toolbar behavior, and adaptive motion. The current MacBook Pro product page is used for the Product Story rhythm (hero, highlights, closer-look sections), not for operational workspaces.
