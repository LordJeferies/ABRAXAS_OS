# He - Content Factory v0.9.3

## Principio
**El formato físico define qué se produce. El patrón define cómo piensa la pieza.**

Cualquier patrón puede adaptarse a otro medio. `NATIVO` significa que el patrón ya nació para ese output; `ADAPTADO` significa que su DNA estructural se traduce.

## Crear pieza
Cliente → output físico → pilar → patrón cliente → patrón universal opcional → tema/contexto → cantidad 1–6 → Coverage Map → estructura → Prompt contenido + Prompt visual.

## Crear lote
Ventana + reutilización + cadencia independiente por lote.

| Lote | Baja | Media | Alta |
|---|---:|---:|---:|
| L1 | 1 Reel + 1 Carrusel/sem | 1 Reel + 1 Carrusel/sem | 2 Reels + 2 Carruseles/sem |
| L2 | 1/sem | 2/sem | 3/sem |
| L3 | 1/sem | 2/sem | 4/sem |

La combinación es libre entre lotes. La ventana multiplica la lógica por 1, 2 o 4 semanas.
