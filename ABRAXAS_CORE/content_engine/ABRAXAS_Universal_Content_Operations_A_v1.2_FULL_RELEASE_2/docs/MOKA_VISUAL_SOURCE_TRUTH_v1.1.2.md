# Moka Bio · Visual Source Truth incorporated in ABRAXAS v1.1.2

This release treats the current Moka assets as visual source material, not as generic inspiration.

## Brand/manual rules incorporated
- Official palette: Pure `#FFFFFF`, Sage `#4E7060`, Deep Forest `#0D2D26`, Fresh Green `#57C378`, Charcoal `#111111`, Birch `#DEDEDE`.
- Typography: Codec Pro as primary content/digital type; Century Expanded as secondary emphasis/editorial type.
- Graphic language: connectivity, thin lines, nodes, organic connections, flows/processes, modular systems, monochrome icons, simple data visualizations, soft support shapes and generous whitespace.
- Visual direction: clean laboratory, botanical/extract macro imagery, microphotography/molecular detail, scientists + technology/AI, and applied product imagery in believable context.
- Content templates use clear hierarchy and, when the composition allows it, approximately 40% text / 60% image as a useful balance rather than a rigid formula.
- Logo integrity: no arbitrary rotation, distortion, recoloring or unnecessary effects.

## Reference-library observations incorporated
The current examples reinforce a premium scientific/editorial direction: macro material detail, biological textures, clean monochrome/green layouts, transparent/glasslike scientific matter, realistic device/product integration, restrained serif emphasis and circular/system diagrams. ABRAXAS prompts must translate these into explicit subject/composition/light/material/texture/continuity rules rather than using adjectives like “premium” alone.
