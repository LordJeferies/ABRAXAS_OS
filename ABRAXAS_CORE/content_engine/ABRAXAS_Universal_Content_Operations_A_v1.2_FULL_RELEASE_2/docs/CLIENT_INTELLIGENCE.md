# Client Intelligence

Cada cliente conserva una identidad estructural propia sin cambiar el shell ABRAXAS.

Capas: Brand Core, Pilares, Formatos/Patrones, Copy Profiles, Branding Method, Sources y accent validado. El accent identifica marca; nunca significa simultáneamente aprobado/publicado/correcto.

Client Intelligence alimenta He, Prompt Composer, assets y QA. Cuando un dato no está validado se mantiene como hipótesis o source gap.
