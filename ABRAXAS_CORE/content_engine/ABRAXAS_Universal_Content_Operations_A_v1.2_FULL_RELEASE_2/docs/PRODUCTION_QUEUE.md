# Production Queue · calm-first

La cola no enseña todo por defecto. Primer nivel: qué resolver. Segundo: contenido. Tercero: una tarea.

Categorías: Copies, Visuales, Video/B-roll, Portadas, QA, Publicación. `Ver todo` es secundario.

Cada Production Task genera un prompt autónomo con content_id, task_id, objetivo, alcance, restricciones, dependencias, salida exacta y QA.
