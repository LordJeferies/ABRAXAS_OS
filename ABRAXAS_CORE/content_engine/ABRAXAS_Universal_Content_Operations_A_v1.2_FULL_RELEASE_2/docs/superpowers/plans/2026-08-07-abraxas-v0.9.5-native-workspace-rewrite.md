# ABRAXAS A v0.9.5 Native Workspace Rewrite Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace SaaS-dashboard anatomy in the storytelling modules with Apple product-story surfaces while preserving the existing Content/Production Graph and macOS workspace modules.

**Architecture:** Keep `src/core.js` and content data contracts intact. Implement the rewrite in `src/app.js` and `src/styles.css` using a new story-mode renderer, local story navigation, Visual/Text mode state, and adaptive shell behavior. Extend runtime/release tests before implementation and keep packaging/build scripts unchanged except for version `0.9.5`.

**Tech Stack:** Standalone HTML, vanilla JavaScript, CSS, localStorage/IndexedDB, inline SVG.

## Global Constraints
- Dashboard, Clients, Brand Intelligence and Roadmap use Apple product-story mode.
- All four support Visual / Solo texto mode and internal minimalist navigation.
- He, Shim, Production, Assets, Calendar and Content Studio remain macOS workspaces.
- El Arquitecto remains a floating right utility window.
- Production Graph, content IDs, tasks, prompts and asset paths are not migrated or renamed.
- No glass-on-glass; glass only on functional layers.
- `prefers-reduced-motion` must be respected.
