# ABRAXAS A v0.9.4 · Architect Edition · Design

## Release intent
v0.9.4 rebuilds the presentation layer over the stable v0.9.3 Production Graph. Apple HIG/WWDC25 is the primary source for hierarchy, navigation, materials, spacing, motion and progressive disclosure. Google/Refero motion is fallback only when Apple does not provide an equivalent behavior.

## Assets
- `assets/branding/abraxas_app_icon_v094.png`: ABRAXAS app icon generated with ChatGPT Image.
- `assets/branding/el_arquitecto_app_icon_v094.png`: Architect/compass app icon generated with ChatGPT Image. The in-app launcher uses a close visual crop through CSS inside an app-icon superellipse; the source PNG stays untouched.
- Both PNGs are embedded as data URIs in the standalone HTML and preserved as physical files in the FULL RELEASE.

## Interface system 2.0 · Architect Edition
Four layers: Environment, Content, Function, Focus. Glass is limited to Function/Focus. Content surfaces remain stable/dark. The shell uses macOS-like sidebar, toolbar, contextual menus, command palette and a single dominant action per workspace. Product-storytelling sections (Dashboard/Brand Intelligence/Roadmap) borrow pacing and spatial composition from Apple product pages rather than copying their assets.

## El Arquitecto Local
A floating compass launcher in the lower-right corner. Opening morphs/expands from the launcher into a contextual panel. Offline-first: no secret API key in HTML. The assistant reads current module, current content, lifecycle, production progress, missing tasks/assets, and local guide knowledge. It starts with a simple explanation of the current location and first action. It exposes preset questions, free-text intent search, navigation/highlight actions, and `Preparar pregunta para IA` which compiles context into a prompt copied/downloadable for external AI.

## Shim Wizard 2.0
Five steps: Fuente → Qué quieres obtener → Estructuras → Revisar → Exportar. Source includes recording name, optional context and timestamped transcript. Outputs include vertical/horizontal clip counts, platform selection, carousel count, structure mode (fixed vs smart distribution), custom structure and final package export as copy/TXT/JSON. Shim never invents transcript wording.

## Brand Intelligence storytelling
Narrative chapters before the 25-tool method: THE CORE, WHO IT IS FOR, WHAT IT BELIEVES, WHAT IT PROMISES, WHAT IT MUST NEVER BECOME, HOW IT LOOKS, HOW IT SOUNDS, HOW TO EXPLAIN IT TO THE CLIENT, HOW TO SELL IT. Branding Method remains a working system below the narrative synthesis.

## Navigation
Sidebar can collapse. When collapsed, toolbar exposes `Herramientas` and `⌘K` command palette. Command palette navigates to tools, saved views, clients and common intents (crear lote, publicar hoy, Shim, Assets). Module workspaces keep distinct internal UX.

## He / Planner
Preserve v0.9.3 physical-output sovereignty, patterns NATIVO/ADAPTADO, micro-batch 1–6 and independent cadence L1/L2/L3 in batch mode.

## Deferred
ABRAXAS Visual Composer (Canva-like static editor) is explicitly deferred to post-v1.0; v0.9.4 only prepares the visual workspace/inspector architecture.
