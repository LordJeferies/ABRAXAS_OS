# ABRAXAS A v0.9.5 · Native Workspace Rewrite — Design

## Goal
Replace the remaining SaaS-dashboard presentation anatomy with an adaptive interface that uses Apple product-story patterns for Dashboard, Clients, Brand Intelligence and Roadmap, while keeping operational modules as macOS workspaces.

## Product-story mode
Applies to Dashboard, Clients, Brand Intelligence and Roadmap.

- Sidebar is collapsed by default and does not dominate the canvas.
- A lightweight local navigation bar identifies the current story and exposes a minimal internal menu.
- Every story surface supports `Visual` and `Solo texto` modes.
- Visual mode uses full-width scenes, large typography, generous whitespace, one primary idea per section, horizontal `Highlights` rails with scroll-snap, and contextual SVG icons.
- Text mode renders the same information as a clean, readable document with the same internal anchors and no decorative staging.
- Story pages use section anchors so internal navigation never requires returning to the global sidebar.

## macOS workspace mode
Applies to He, Shim, Production Queue, Assets, Resultados IA, Calendar and Content Studio.

- Compact inset sidebar appears because navigation is useful during work.
- Toolbar stays minimal and secondary commands move into menus.
- Content surfaces remain stable/dark; glass is restricted to navigation, controls, popovers and focus surfaces.
- El Arquitecto remains a floating utility window on the right and never participates in page grid layout.

## Dashboard anatomy
1. Hero scene: one statement and one operational CTA.
2. Get the highlights rail: Production, This week, AI handoffs, Ready to publish, client focus.
3. Decision scene: what needs attention now.
4. Weekly planning scene with one large summary rather than a matrix of metrics.
5. Client story scene.

No four-card KPI grid is allowed in the opening viewport.

## Clients anatomy
- Hero: “Four brands. One operating system.”
- Highlights rail: one large client card per client.
- Selecting a client opens an anchored narrative with Core, Positioning, Formats, Copy Profiles and Branding Method summary.
- Internal local navigation remains visible.

## Brand Intelligence anatomy
Full narrative chapters: Core, Who it is for, Beliefs, Promise, Boundaries, Look, Sound, Explain to client, Sell it, Branding Method. Each chapter is a large scene; deeper editing is progressively disclosed.

## Roadmap anatomy
- Product-story hero.
- Horizontal milestone highlights.
- A connected growth narrative from Seed → Roots → Trunk → Branches → Canopy → Ecosystem.
- Text-only mode provides the same roadmap in a clean linear document.

## El Arquitecto
- Floating right utility window, fixed independently from page layout.
- Closed state is the compass launcher.
- Open state is 380–420px wide, top aligned below toolbar, rounded like a macOS utility window.
- Contextual guidance remains offline and knows current section/content/task state.

## Motion
- Apple-first: restrained opacity/translate reveal, source-anchored popovers, scroll-snap rails, light spring only for utility surfaces.
- `prefers-reduced-motion` removes nonessential movement.

## Visual constraints
- No SaaS metric-card opening grid.
- No glass-on-glass.
- No more than four visible hierarchy levels.
- No icon-in-square repetition for story surfaces; use contextual SVG icons integrated into scenes.
- Internal story nav uses minimal text labels and active underline/indicator.
- Maintain ABRAXAS dark palette and client accents as Apple would use them: selectively for focus, not for every surface.
