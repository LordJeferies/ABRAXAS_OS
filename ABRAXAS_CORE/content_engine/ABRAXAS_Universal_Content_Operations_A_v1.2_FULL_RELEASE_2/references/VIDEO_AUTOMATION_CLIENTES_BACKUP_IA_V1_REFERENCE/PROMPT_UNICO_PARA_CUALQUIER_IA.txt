Voy a entregarte un video master largo y un archivo de texto/HTML/JSON que describe clips mediante timestamps. Esos clips todavía no existen: cada uno puede tener uno o varios segmentos del master, incluso en orden no cronológico. Lee primero el contexto adjunto. Tu primera tarea es convertir el archivo editorial a un `manifest.json` sin alterar timestamps ni orden. Después crea una automatización reutilizable por cliente para generar esos clips mediante Terminal/FFmpeg, DaVinci Resolve o ambos. La arquitectura debe permitir añadir luego, sin rehacer cortes: framing, punch-ins, mejora de voz, subtítulos IA, glosario, SRT, Text+, logos, B-roll y render por lote. Todo debe tener backups, logs, reanudación, verificación, cero gaps/overlaps y hotfixes acumulativos. En DaVinci usa Workspace→Console→Py3 y diagnostica la API local antes de asumir métodos. Nunca destruyas trabajo válido para arreglar una etapa posterior.
