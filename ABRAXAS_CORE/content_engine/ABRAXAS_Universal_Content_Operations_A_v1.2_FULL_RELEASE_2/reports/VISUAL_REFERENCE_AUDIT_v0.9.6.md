# ABRAXAS v0.9.6 · Visual Reference Audit

## Apple product pages
The structural reference is MacBook Pro / iPhone Pro: compact product navigation, restrained hero typography, wide `Get the highlights` rails, `Take a closer look` selector patterns, alternating media-led scenes, detail disclosures, and clear shifts between black and light/fog surfaces. The release uses these as information-architecture rules rather than decorative imitation.

## Apple HIG / WWDC25
Liquid Glass is reserved for functional chrome: navigation, floating controls, popovers, segmented controls and the Arquitecto utility window. Content surfaces remain stable. Motion is source-anchored, context preserving and removed under `prefers-reduced-motion`.

## Dala
Only the procedural particle-field idea is adopted. Dala's uploaded reference describes thousands of triangular particles forming a brain on a pure black canvas. ABRAXAS replaces those with open A/chevron particles in bone/gold/bronze, and the field morphs through five information states as Home scrolls.

## OHZI
Used only for the idea of an immersive single visual object in a dark gallery. Its sharp grayscale UI is not copied; Apple remains the UI authority.

## CleanMyMac recordings
Operational tools use a dominant center-stage task, one primary action, visible progress/state, a compact module navigator and contextual secondary controls. This informs He, Shim and Production without applying CleanMyMac's exact assets.

## Uploaded web/video references
The six screen recordings were sampled at multiple timestamps. Repeated useful patterns: horizontally navigated highlights, single-topic scenes, selector-driven detail, large but not overwhelming media objects, persistent lightweight navigation, process/state visualization, and alternating information density.

## Moka references
Moka's visual language explicitly uses connectivity lines/nodes, flows/processes, modular systems, simple charts, monochrome icons and broad whitespace. These principles are retained when Moka is the active client; the global ABRAXAS shell does not overwrite them.
