===============================================================================
SOURCE TRUTH
===============================================================================

Priority:
current user instruction
> approved manifest
> exact timestamp
> audio/video master
> literal transcript
> ASR
> editorial inference.

No invented speech.
No invented word-level timecodes.
No source rewrite presented as quote.

===============================================================================
VERTICAL VIDEO
===============================================================================

Runtime:
50–90 s hard gate.

Split transcript into semantic beats <=9 s for production planning.

Select 3–4 best VFX/B-roll opportunities.
Prioritize:
- hook;
- mechanism;
- example;
- consequence;
- contrast;
- data/relationship;
- payoff.

Do not force treatment when presenter is stronger.

Each selected opportunity gets the full Visual Motion Pack:
START/MIDDLE/END
× WITH_TEXT/NO_TEXT
+ ANIMATION_WITH_TEXT/NO_TEXT.

===============================================================================
HORIZONTAL VIDEO
===============================================================================

Runtime:
8–12 minutes.

Must include:
- cold open;
- thesis;
- chapters;
- attention resets;
- examples/evidence;
- payoff.

Create approximately one <=9 s visual intervention per source minute.

This is a density target, NOT:
“at 00:01:00 add effect”.

Select the most useful moment in/around that minute.

If one minute has no useful visual treatment:
move the opportunity to a neighboring chapter rather than adding filler.

===============================================================================
PRINCIPAL CAROUSELS
===============================================================================

Slide 1:
- real pain point;
- context;
- clear promise.

The carousel must feel more explanatory than earlier systems.

Possible editorial modes:
EXPLAINER
NEWS
ANALYSIS
FRAMEWORK
TIPS
HYBRID.

Tips must come from source/evidence.
Do not generate generic tips just to fill slides.

Progression examples:
PAIN → CONTEXT → WHY → MECHANISM → CONSEQUENCE → DECISION → PUNCH.
NEWS → WHAT CHANGED → WHY IT MATTERS → MECHANISM → WHO IT AFFECTS → ACTION.
ERROR → DIAGNOSIS → CRITERION → EXAMPLE → TIP → DECISION.

Every slide:
- function;
- exact text;
- source note;
- visual direction;
- prompt no text;
- prompt with text;
- QA.

===============================================================================
HIGHLIGHT CAROUSELS
===============================================================================

Podcast/interview:
create 6:
- 2 HOST.
- 2 GUEST.
- 2 MIXED.

Single speaker:
6 SINGLE_SPEAKER.

Each highlight carousel:
- based on one coherent source section;
- slide 1 = hook;
- each slide = max two short phrases;
- use exact quote or rotulated paraphrase;
- 1 or 2 visual images only when composition benefits;
- final slide = super-punch / payoff / strongest relevant idea.

Not:
quote account;
random quotes;
phrase dump;
screenshots without progression.
