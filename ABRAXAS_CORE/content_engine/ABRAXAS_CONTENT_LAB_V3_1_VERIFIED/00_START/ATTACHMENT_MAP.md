- SHARED_CORE.md
- INTRO_LAB_CRITERION.md
- PROMPT_NEW_CHAT_INTRO_LAB.txt
- el HTML del episodio o transcript/timestamps
- masters V/H si vas a resolver microtrims
- referencias visuales/brand pack

No necesitas adjuntar CONTENT_ENGINE_CRITERION.md.

## Modificar el sistema

Adjunta TODO el ZIP y pide MODE=SYSTEM_UPDATE.
La IA debe producir impacto map, changelog, regression test y migration note; no debe editar solo un prompt.

## Regla práctica

HTML = qué se aprobó/producirá.  
Criterion = qué significa hacerlo bien.  
Prompt = cómo instruir a una IA en contexto cero.  
Automation = cómo convertir lo aprobado en archivos.  
QA = cómo demostrar que no se degradó.
