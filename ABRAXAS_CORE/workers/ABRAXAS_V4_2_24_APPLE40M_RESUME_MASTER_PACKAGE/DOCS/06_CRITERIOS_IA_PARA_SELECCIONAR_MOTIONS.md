# Criterios IA para M1–M6

| Motion | Usar cuando | Contrato obligatorio |
|---|---|---|
| M1 | Detalle, exploración u observación material | Placa flexible y tres observaciones; no generar al speaker |
| M2 | Progresión, transformación o símbolo evolutivo | 4 placas limpias + 3 variantes con palabras exactas contiguas |
| M3 | Tesis, contradicción o payoff verbal | Tipografía editorial pura; no subtítulo ni quote card |
| M4 | Proceso, sistema o relación | Una infografía maestra 4K recorrida en Z; no cuatro slides |
| M5 | Acción física verificable | Plano general, detalle y resultado; no intro genérica |
| M6 | Software o datos verificables | Input, proceso y output; sin HUD/cyberpunk ni UI inventada |

Prioridad de evidencia: tratamiento aprobado → función narrativa → significado de la frase → posibilidad física de representación → keywords. Si el recurso reduce el valor del rostro o gesto humano, se mantiene source o se usa la alternativa aprobada.
