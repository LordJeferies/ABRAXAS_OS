# Reglas horizontales

- IDs exactos: H01–H04, JH01–JH04 y MH01–MH04; total 12.
- Duración obligatoria: 8–12 min para cualquier variante.
- El programa se conserva completo; no se trocea por cada Motion.
- Objetivo creativo: aproximadamente dos oportunidades útiles por minuto.
- Límite de distribución: máximo dos inicios por minuto de reloj.
- Ventana individual: 4–9 s.
- H03 conserva el override histórico de 12:00 exactos mediante trim final de 1 s.

El mapa actual asigna entre 18 y 24 oportunidades por horizontal y 255 en total. La densidad individual queda entre 1.946 y 2.051 por minuto, producto del redondeo entero.
