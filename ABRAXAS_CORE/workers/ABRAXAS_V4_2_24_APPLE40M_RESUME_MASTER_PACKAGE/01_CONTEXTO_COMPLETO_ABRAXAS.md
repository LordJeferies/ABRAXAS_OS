# Contexto completo de ABRAXAS

ABRAXAS es un sistema HTML Driven Automation para la producción del episodio JOC55 con Amanda Vicari. Sus dos HTML canónicos describen editorialmente qué producir; la automatización compila esos contratos, localiza medios, crea carpetas y TXT, renderiza programas fuente y prepara el handoff de Motion/DaVinci.

El sistema contiene:

- Intro Lab: seis rutas de introducción, tres guest-only y tres mixtas.
- Content Engine: 37 verticales y 12 horizontales, además de carruseles, frases, claims y potenciales.
- Motion System V7: contratos M1–M6 para activos y animación.
- Motor semántico V4.2.24: decide ventanas útiles, motion, motivo y orden.
- Renderer heredado V4.2.5: crea los programas fuente completos, con cache y reanudación.
- Handoff: manifests, prompts, assets, pistas y rangos exactos para DaVinci.

La fuente de verdad no es un solo script histórico. Es la intersección validada entre los HTML V4.2.5, el SRT, las resoluciones de microtrim, Motion System V7 y los contratos explícitos V4.2.24.
