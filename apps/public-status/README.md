# ABRAXAS Public Status V3 — Dedicated Frontend Builder

This package is the dedicated, isolated build owner for the ABRAXAS OS Public Status website.
It compiles the real Three.js / GSAP Spatial Pyramid experience into deterministic static assets in `docs/abraxas-os-status/`.

## Stack
- Vanilla Semantic DOM & Modular ES6 JS
- Native Three.js (`0.185.1`)
- Native GSAP & ScrollTrigger (`3.15.0`)
- Vite (`8.2.2`)
