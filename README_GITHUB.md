# ABRAXAS OS

This repository is the unified source-control baseline for the ABRAXAS OS ecosystem.

## Main areas

- `ABRAXAS_CORE/` — editorial automation, content systems, motion intelligence and workers
- `VAV/` — audiovisual editing platform and product ecosystem
- `SHARED_KNOWLEDGE/` — shared rules/contracts/knowledge
- `00_START_HERE/` — maps and current system state

Heavy runtime, media, evidence, backups, archives and quarantine are intentionally
kept outside Git history. See `00_START_HERE/GITHUB_MONOREPO_BASELINE.md`.
