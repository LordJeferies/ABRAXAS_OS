1. What It Is & Purpose

Contenido is the persistent, versioned identity of a content piece. The current implementation may still use the name Lienzo. Revisions preserve history; dependencies remain explicit; downstream derivatives can become OUT_OF_SYNC without destroying previous artifacts.

3. Problem Solved

Prevents state corruption, untracked overwrites, and cascade breakage across editorial, cut, caption, and render stages by maintaining an immutable versioned DAG.

4. Operational Example Flow

Plan accepted -> Contenido draft created -> Media ingested -> Timestamped script attached -> Revision 2 locked -> VAV consumes Revision 2 for cut assembly.

5. Strict Ownership Boundaries

✓ What CONTENIDO (LIENZO) OWNS

  • Canonical content data document (JSON schema)
  • Immutable revision history & strata hashing
  • Explicit DAG dependency graph between assets
  • OUT_OF_SYNC cascade invalidation marking
  • Deterministic patch mutation resolution

✗ What CONTENIDO (LIENZO) DOES NOT OWN

  • Does NOT own creative generation logic (YOD owns this)
  • Does NOT own human workflow status or calendar (HE owns this)
  • Does NOT own video encoding or timeline rendering (VAV owns this)
  • Does NOT own UI layout components or projection views
