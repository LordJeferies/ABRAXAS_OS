🛠️ EN PROFUNDIDAD // LA ECUACIÓN DE GAP

Metrología de Discrepancia Levenshtein

SHIM calcula la distancia de edición fonética entre el texto planificado (T_plan) y el audio transcrito (T_audio). Si la similitud cae por debajo del 98.5%, se emite un GAP alert con código de tiempo exacto.

GAP_SCORE = 1.0 - (LevenshteinDistance(T_plan, T_audio) / MaxLength) -> PASS if GAP == 0.00%
FÓRMULA MATEMÁTICA // LEVENSHTEIN GAP SCORE

Cálculo Fonético: La distancia de Levenshtein se normaliza sobre la longitud del vector de palabras $N = max(|T_{ ext{plan}}|, |T_{ ext{audio}}|)$:

ext{GAP} = rac{ ext{dist}(T_{ ext{plan}}, T_{ ext{audio}})}{N} imes 100%

Solo los activos con $ ext{GAP} = 0.00%$ o con sobreescritura manual firmada pasan al compilador de Remotion.
