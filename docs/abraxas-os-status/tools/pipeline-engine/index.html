Pipeline Engine

Batch Orchestration & Stage Execution

Coordinates multi-stage asset generation, offline compilation, and rendering pipelines.

01. What & Why

Definition: The deterministic DAG orchestrator executing modular content pipelines.

Why It Exists: Enables flexible reordering, node skipping, and cascading failure recovery across multi-stage production workflows.

02. Ownership Boundaries

✓ Owns

  • Pipeline DAG validation & cycle rejection
  • Topological node execution
  • Conditional node skipping & failure cascade
  • Execution result aggregation

✗ Does Not Own

  • Does NOT own individual module domain logic (modules own their handlers)
  • Does NOT own content state (Lienzo owns this)

03. Contracts & Data Flow

Inputs:
  • PipelineDefinition
  • ModuleHandlers
  • ExecutionContext
Outputs:
  • PipelineExecutionResult
  • NodeExecutionLogs
Example Lifecycle Flow:

Blueprint selected -> DAG topologically sorted -> Stage 1 executes -> Stage 2 skipped if configured -> Stage 3 completes.
