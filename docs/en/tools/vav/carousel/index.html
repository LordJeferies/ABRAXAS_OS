VAV SÍNTESIS // MOTOR DE CARRUSELES 4:5 & ANIMACIÓN

VAV Carousel.
From Clean Plates to Animated Slides.

Place high-impact typography on clean background plates, layer PNG elements intelligently, and convert static carousels into animated micro-videos.

⚡ EN 30 SEGUNDOS // RESUMEN EJECUTIVO

Total Typographic & Visual Control

  • 📁 Carga Automática de Carpeta: Arrastra tus fotos limpias a la carpeta indicada por Arquitecto y el sistema monta los textos del guion al instante.
  • ✍️ Animación de Letras: Elige entre aparición letra a letra (Typewriter), palabra por palabra elástica o fade-in en bloque.
  • 📄 Composición de PNGs Sugeridos: Ubica stickers, diagramas y capturas con efecto 'Paper-Cut' o difuminado suave.
  • 🎬 Doble Salida: Exporta tanto en imágenes estáticas 4:5 de alta definición como en video animado 60 FPS para Instagram y TikTok.
MODO MANUAL & AGENTES IA

Puedes dejar que los agentes de IA redacten y ubiquen los textos automáticamente, o intervenir manualmente con el editor visual para ajustar kerning, safe zones y jerarquías.

🛠️ EN PROFUNDIDAD // MOTOR DE DISPOSICIÓN ESPACIAL

Safe Zones & Contrast Detection

VAV Carousel computes 16x16 luminance grids and injects subtle gradient backdrops ensuring WCAG AAA readability.

carouselRules: { aspect: '4:5', safeMargin: '108px', textContrast: 'AAA', font: 'SF Pro Display' }
ESPECIFICACIÓN DE RENDER

Renderizado vectorial por Remotion SVG + Canvas a 2160x2700px (calidad Retina 8K sin pixelación).

AUTOMATIZACIÓN // INGESTA DE CARPETA

Automated Staging from Clean Plates

Arquitecto te indica la ruta de la carpeta del proyecto (ej. /activos/carrusel_04/plates/). Al guardar tus imágenes sin texto allí, VAV Carousel lee el guion del Lienzo, detecta el número de diapositivas (1 a 10) y genera una previsualización con la tipografía oficial, números de página y llamadas a la acción perfectamente alineadas.

Soporta formatos WebP, PNG, TIFF y JPG con asignación automática de orden por nombre de archivo.

CINÉTICA // ESTILOS DE ANIMACIÓN DE TEXTO

Typography Animation Styles

MODO 01

Typewriter (Máquina de Escribir)

Las letras aparecen una a una con cursor parpadeante, creando intriga y retención de lectura.

Velocidad configurable: 25ms a 60ms por carácter con micro-sonido mecánico opcional.

MODO 02

Kinetic Elastic Pop

Las palabras clave entran con un sutil rebote elástico (spring) para enfatizar datos y números.

Física Remotion con mass: 0.4 y stiffness: 120 para un impacto enérgico y moderno.

MODO 03

Smooth Block Fade

Disolvencia suave y elegante de oraciones completas para marcas de lujo y estética sobria.

Transición de opacidad de 0 a 100% en 300ms con curva de aceleración cubic-bezier.

COMPOSICIÓN // CAPAS PNG & PAPERCUT

PNG Layering & Paper-Cut Animation

Cuando arrastras elementos PNGs transparentes (gráficos de barras, capturas de pantalla, sellos dorados o iconos), VAV Carousel sugiere la posición espacial óptima y aplica estilos de animación como:

  • ✂️ Efecto Paper-Cut: El PNG entra cayendo con sombra paralela realista como si se pegara sobre el papel.
  • 🌫️ Difuminado Gaussian Reveal: Aparece desde un desenfoque progresivo suave.
  • 🎈 Flotación Sutil: Micro-movimiento senoidal oscilatorio para dar vida a la diapositiva en formato video.

Cálculo de sombras dinámicas con CSS drop-shadow(0 12px 24px rgba(0,0,0,0.45)).
