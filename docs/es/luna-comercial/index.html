ARQUITECTURA SQLITE // BIPARTICIÓN ESTRICTA DE LUNA 3

Separación Inmutable: Costos de Fábrica vs. Ventas de Mercado

Los costos operativos de equipo y las ventas registradas por OCR nunca se mezclan en las mismas tablas. Se auditan por separado y solo se cruzan en una vista sintética de ROI.

BÓVEDA A // COSTOS DE MANUFACTURA (INTERNO)

Tiempos, Cuellos de Botella y Fábrica

  • ⏱️ Tabla manufacturing_time_entries: Registra segundos exactos trabajados en Guion, Set SHIM, Edición VAV y QA.
  • 🚨 Tabla manufacturing_bottlenecks: Mide tiempos muertos (idleSeconds) y detecta bloqueos del equipo.
  • 💵 Tabla manufacturing_cost_ledger: Calcula el costo exacto de manufactura por pieza ($/activo) sumando horas de colaboradores y overhead.
BÓVEDA B // INGRESOS Y VENTAS (EXTERNO)

Facturas OCR, WhatsApp y Closers

  • 📸 Tabla sales_ocr_invoices: Ingesta fotos y PDFs de facturas extrayendo monto, fecha y producto on-device.
  • 💬 Tabla sales_revenue_ledger: Consolida ingresos brutos y netos atribuidos a cada contentId en WhatsApp y web.
  • 👥 Tabla closers_transactions: Registra el desempeño de los vendedores y comisiones liquidadas.
CRUCE SEGURO // VISTA SQL DE P&L Y ROI

Cálculo Matemático Dinámico en SQLite (metrics.db)

CREATE VIEW v_asset_pnl_roi AS SELECT c.content_id, c.total_manufacturing_cost, s.net_revenue_usd, ((s.net_revenue_usd - c.total_manufacturing_cost) / c.total_manufacturing_cost) * 100 AS roi_percentage FROM manufacturing_cost_ledger c LEFT JOIN sales_revenue_ledger s ON c.content_id = s.content_id;

04 // FÓRMULA DE RETORNO SOBRE INVERSIÓN (ROI DE CAMPAÑA)

Cálculo Matemático de Rentabilidad Real

\[ \text{ROI} = \frac{\text{Facturación Atribuida} - (\text{Costo de Producción} + \text{Pauta Comercial})}{\text{Costo de Producción} + \text{Pauta Comercial}} \times 100\% \]

Dado que el costo de producción con ABRAXAS OS en Apple Silicon es cercano a cero (0.00 USD en horas de edición humana y GPU local), el ROI de cada campaña se dispara exponencialmente.
